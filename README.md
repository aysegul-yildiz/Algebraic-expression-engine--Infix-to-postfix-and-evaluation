# Algebraic-expression-engine--Infix-to-postfix-and-evaluation
This project was done for CS 201 course in 2022 implements a mathematical expression engine that converts standard Infix notation like 3 + 4 * 2 into postfix and evaluates the result. 
AlgebraicExpression.h: header file defining the class interface and precedence
AlgebraicExpression.cpp: Core implementation containing the conversion and evaluation algorithms
